Find out the syllabus of GATE for DSA
=====================================

GATE SYLLABUS FOR DSA

Programming and Data Structures:
  - Programming basics: programming in C, variables, control flow, functions,
    recursion.
  - Linear data structures: arrays, strings, stacks, queues, linked lists.
  - Trees: general trees, binary trees, binary search trees, basic operations.
  - Heaps: binary heaps, priority queues, basic heap operations.
  - Graphs: representation, basic graph theory concepts.
  - Hashing: hash tables, hash functions, collision handling.

Algorithms:
  - Searching: linear and binary.
  - Sorting (basic): bubble, selection and insertion.
  - Sorting (advanced): merge, quick, heap sort, divide and conquer idea.
  - Complexity: asymptotic worst-case time and space complexity, Big-O, omega,
    theta.
  - Algorithm design techniques: greedy, dynamic programming, divide-and-conquer.
  - Graph algorithms.
